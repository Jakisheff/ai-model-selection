# Model Selection Exercises

This repository contains exercises focused on advanced model selection techniques in machine learning, including K-Fold Cross-Validation, GridSearchCV, and Learning/Validation Curves.

## Prerequisites

- Python 3.9+
- Virtual environment (recommended)

## Setup

1.  Create and activate a virtual environment:
    ```bash
    python -m venv ex00
    source ex00/bin/activate  # On Windows use `ex00\Scripts\activate`
    ```

2.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Running the Exercises

1.  Launch Jupyter Notebook:
    ```bash
    jupyter notebook
    ```

2.  Open `task.ipynb` and execute the cells sequentially to complete the exercises.

## Overview of Exercises

-   **Exercise 0**: Environment Setup.
-   **Exercise 1**: K-Fold Cross-Validation manual implementation.
-   **Exercise 2**: Cross-Validation with Linear Regression.
-   **Exercise 3**: GridSearchCV with Random Forest.
-   **Exercise 4**: Visualizing Validation and Learning Curves.
